# Space Detective (محقّق الفضاء الصغير) — Project Brief

## 1. Executive Summary

- **Project Name:** Space Detective
- **Arabic Title:** محقّق الفضاء الصغير
- **Type:** Interactive 3D Educational Browser Game
- **Target Audience:** Children aged 4–6 years old
- **Primary Interface Language:** Modern Standard Arabic (RTL orientation)
- **Deployment Mode:** Client-side Single-File Web Application (`index.html`)

**Space Detective** introduces early childhood learners to modern media literacy in a supportive, play-driven cosmic universe. Players embark on an interstellar journey with "Cosmo" (كوزمو), an enthusiastic robot detective assistant, traveling across three unique planets to analyze visual transmissions. The core educational objective is teaching children to distinguish verified real-world photographs from AI-generated visual content using observational inquiry, curiosity, and supportive audio-visual feedback.

---

## 2. Target Audience & Developmental Considerations

Designing for children aged 4 to 6 requires strict adherence to developmental psychology and usability principles:

| Consideration | Design Implementation |
| :--- | :--- |
| **Emergent Literacy** | Instructions are spoken aloud in friendly Arabic using the Web Speech API; visual icons and color coding accompany all text. |
| **Motor Skills** | Large touch targets (minimum 64px height), generous spacing, and zero reliance on precise drag-and-drop or complex gestures. |
| **Attention Span** | Short, engaging game loops (3–5 questions per planet mission) with instant, delightful rewards. |
| **Emotional Safety** | No "Game Over" screens, zero loss penalties, and non-threatening sound effects; incorrect choices yield constructive coaching hints. |
| **Cultural Context** | Native Arabic RTL typography, culturally familiar conversational cadence, and accessible vocabulary. |

---

## 3. Educational Objectives & Media Literacy Framework

### Primary Educational Goal
Empower young children with foundational media awareness by introducing the concept that visual imagery can either be a real capture of the physical world (photograph) or a creative picture generated by computer intelligence (AI image).

### Crucial Pedagogical Guidelines
1. **Never teach false heuristics:** Young children should never be taught that visual flaws (e.g., "blurry textures", "distorted hands") are definitive proof of AI, as generative technology rapidly improves and real photos can also contain distortions or motion blur.
2. **Promote inquiry over skepticism:** The game cultivates curiosity about how images are made and where they come from (cameras vs. computer tools).
3. **Verified Datasets:** Every image in the game has a known, verified provenance ground-truth label, categorized by child-friendly themes (animals, space objects, nature, everyday toys).

## 4. Main Game Concept & Narrative

- **The Setting:** The Astral Observatory aboard the Starship Discovery, gazing into deep space illuminated by glowing nebulas, distant stars, and orbiting planets.
- **The Protagonist Guide:** Cosmo (كوزمو), a friendly, round-bodied 3D robot equipped with expressive glowing eyes, animated antennas, and gesture-driven reactions.
- **The Mission:** Earth and other celestial stations are sending visual transmissions to the ship's holographic scanner. Cosmo needs the player's sharp detective eyes to categorize these pictures into the "Real Space Archive" or the "AI Creative Laboratory".
- **Progression:** Completing missions on the **Moon Planet (كوكب القمر)** unlocks the **Colorful Planet (الكوكب الملوّن)**, which in turn unlocks the **Galaxy Planet (كوكب المجرة)**.

---

## 5. Core Feature Set

1. **Immersive 3D Space Environment:** Real-time Three.js scene featuring floating cosmic particles, distant rotating planets, dynamic lighting, and an animated robot character.
2. **Arabic Voice Narration:** Web Speech API integration that speaks questions, encouragement, and educational hints in clear Arabic.
3. **Intuitive Dual-Choice Interface:** Simplified child-centric action buttons with distinct colors, glowing borders, and recognizable icons (Camera 📷 for Real Photo vs. Magic Wand / Robot 🪄 for AI Image).
4. **Gentle Feedback Loop:** Animated celebrations, sparkling particle effects, and cheerful audio for correct answers; supportive visual hints for alternative choices.
5. **Star Rewards & Cosmic Badges:** Cumulative star rewards for each completed planet without competitive stress.
6. **Zero-Setup Portability:** Bundled entirely within `index.html` for instant loading on any standard classroom or home device.

---

## 6. Technical Architecture & Constraints

- **Single-File Game Architecture:** All HTML, CSS, JavaScript, game state, asset references, and shaders reside inside `index.html`.
- **Pure Web Standards:** HTML5, CSS3, ES6+ Vanilla JavaScript.
- **No Build Tools:** Zero dependency on Webpack, Vite, Parcel, Node.js runtime, npm packages, or bundlers.
- **External Dependencies:** Three.js (r128+ via CDN) and GSAP (via CDN, optional for timeline choreography).
- **Responsive Layout:** Dynamic viewport scaling supporting 16:9 desktop monitors, 4:3 / 3:2 tablets, and mobile portrait/landscape orientations.
- **Performance Budget:** Targeted 60 FPS on integrated GPUs and standard mobile hardware through geometry instancing, low-poly Three.js meshes, and optimized particle counts.

## 7. Expected Final Experience

When the child launches the game:
1. They are greeted by a deep neon space landscape with gentle cosmic ambient particles and a waving 3D robot speaking in Arabic: *"مرحباً بك يا بطل الفضاء! أنا كوزمو، هل أنت مستعد لمغامرة التحقيق الكونية؟"*
2. They tap the glowing "Start Adventure" button and choose an unlocked planet.
3. Transmissions appear one by one inside a high-tech holographic scanning frame.
4. With clear voice guidance and vivid imagery, the child taps their deduction.
5. Upon mission completion, stars shower the screen, Cosmo dances with joy, and the next planet unlocks.
6. The experience concludes with a celebratory victory screen honoring the child as an "Official Space Detective" (محقّق الفضاء المعتمد).
